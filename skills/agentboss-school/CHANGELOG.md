# Changelog

All notable changes to AgentBoss School are recorded here. Versions follow semantic versioning for the installable Skill package; credential meaning remains separately versioned by `credentialType` and course version.

## 0.7.1 — 2026-08-25

- Added standalone Node.js validation commands and GitHub Actions.
- Added public security reporting and local-sensitive-file exclusions.
- Prepared the curriculum as an independently publishable GitHub repository.

## 0.7.0 — 2026-08-24

- Expanded thin lessons with source-bounded decision walkthroughs.
- Added three progressive-disclosure practice scenarios with structural scoring and blocking failures.
- Added human-factors research on calibrated reliance, out-of-the-loop performance and human–automation coordination.
- Preserved the boundary that machine practice scores do not replace mentor judgment or prove production competence.

## 0.6.0 — 2026-08-24

- Completed 24 core knowledge nodes and 6 shared Labs.
- Added claim and source governance, case RAG, signed Foundations credentials and opt-in Yearbook support.
