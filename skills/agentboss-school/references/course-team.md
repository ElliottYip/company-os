# 课程地图：把方法带进团队

## 课程结果

学生能够设计一个有基线、责任、评测门、运营节奏、退出条件和移交方案的 Agent 试点，并在免费课程、可选陪跑和 FDE 之间保持清晰边界。

## 可用节点

| 节点 | 主要决定 | lesson |
|---|---|---|
| `team/pilot` | 是否、怎样开展一次可学习且可退出的试点 | `lessons/team/01-pilot.md` |
| `team/role-design` | 真人与 Agent 的责任、审批、评测和升级如何分工 | `lessons/team/02-role-design.md` |
| `team/operating-review` | 如何以证据决定继续、收紧、回退或停止 | `lessons/team/03-operating-review.md` |
| `team/skill-as-process` | 如何把一次做法变成可版本化、可评测、可回退的 Skill | `lessons/team/04-skill-as-process.md` |
| `team/value-and-economics` | 是否创造可验证净价值并值得长期维护 | `lessons/team/05-value-and-economics.md` |
| `team/change-and-handoff` | 长期团队能否独立运行、接管和退役 | `lessons/team/06-change-and-handoff.md` |
| `shared/demo-responsibility-loop` | 建立共同责任语言 | `lessons/shared/01-demo-responsibility-loop.md` |
| `shared/team-pilot-studio` | 完整验证 Team Lead 的试点与移交能力 | `lessons/shared/06-team-pilot-studio.md` |

## 路由

- 没有本地评测：先去 `operations/evaluate-and-review`。
- 只想部署工具、没有业务基线：进入试点设计。
- 课程方法能独立执行：继续免费路径。
- 需要带领团队练习和运营节奏：可选 Agent Boss 陪跑。
- 需要现场流程发现、系统集成或生产交付：可选 FDE 诊断。

任何付费服务都不能替代课程证据、购买证书或强制公开 Yearbook 名字。

团队六个核心节点已齐备。推荐图谱是：责任语言 → 角色设计 → 试点 → 运营复盘 → Skill 流程化 → 价值决定 → 变更移交；已有证据时允许跳转，不按文件编号机械推进。
