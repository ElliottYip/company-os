# 团队第一课：设计可退出、可学习的试点

## 学习结果

学生能设计一个有基线、边界、责任、评测、运营节奏、退出条件和移交计划的 Agent 试点，不把购买工具或完成 demo 当采用成功。

## 核心概念

试点是验证业务与组织假设的受控实验。它必须同时测量结果质量、风险事件、真人时间、成本、延迟和工作变化，并保留停止或回退能力。

## 决策框架

选择高价值但影响半径可控的工作；记录现状基线；指定流程所有者、负责真人和受影响人员；定义任务集与上线门；限定数据、权限和时间；设周度运营复盘；预先写继续、收紧、扩大和停止条件。

## 讲授

试点目标不应是“上线一个 Agent”，而应是例如“在不增加政策违规的情况下，把合格简报准备周期从基线缩短，并保持事实核验”。若基线不存在，就无法区分新工具效果、任务变化和选择性展示。

一线参与者知道例外、隐性工作和接管难点。让他们参与合同、失败样本和培训设计，既不是把责任甩给员工，也不是用满意度替代结果证据。

### 试点真正验证三类假设

第一类是**任务假设**：这个工作是否足够清楚、重复且可验收；第二类是**系统假设**：Agent 在本地数据、权限和工具条件下能否稳定工作；第三类是**组织假设**：谁会观察、接管、复盘和维护。只验证模型输出而不验证组织接管，最多得到一个 demo。

销售主线中，团队想让 Agent 自动生成跟进建议并写入 CRM。合理的第一阶段不是开放全量客户写权限，而是从历史脱敏机会中建立基线和评测集，再让 Agent 在隔离环境生成建议草稿。只有质量、拒绝行为和责任流程过门，才进入少量真实但低风险的影子运行。

### 用阶段门控制扩大

试点可以分成四个阶段，每个阶段都有进入和退出条件：

1. **离线验证**：使用获准历史或合成数据，检查任务定义、评测和失败分类；
2. **影子运行**：Agent 生成结果但不影响真实流程，与现有工作并行比较；
3. **受限辅助**：真人使用建议，外部动作仍由真人完成，收集接管与节省时间证据；
4. **有限委派**：只对已证明稳定的低风险部分开放有界动作，持续抽样和回退。

阶段不是必须全部走完。若任务价值不成立、政策违规出现、真人负担增加或无法可靠验收，停止本身就是成功的试点结论。试点的职责是减少不确定性，不是证明采购决定正确。

### 基线不能只看处理时长

至少记录当前质量、周期、人工投入、返工、异常和风险事件。Agent 减少了起草时间，却增加核验和事故处理，净价值可能为负。成本也不只包括模型调用，还包括集成、评测、观察、审批、培训和维护。

员工参与不是做满意度调查。一线人员应帮助列出例外、定义可接受结果、设计接管界面，并明确哪些判断仍由人完成。流程所有者负责业务结果，技术所有者负责系统运行，两者不能互相代替。

### 四种决策必须预先写好

- **继续**：指标达到门槛，风险在边界内，保持当前范围收集更多证据；
- **收紧**：出现可定位问题，减少数据、权限、任务或自治后再验证；
- **扩大**：当前阶段稳定，且下一阶段新增风险和运营资源已明确；
- **停止**：价值不足、阻断风险、无法验收或组织无人接管，回退到原流程。

如果只有“成功后全面推广”，试点已经变成一条单向采购隧道。

### 示范工作件：一页试点画布

```text
问题：销售跟进建议准备慢且口径不一致；先验证内部草稿，不自动联系客户。
现状基线：记录准备周期、返工、事实错误和真人核验时间；当前尚无结论。
范围：指定团队、指定机会类型、限定时间；客户外发和自动写 CRM 在范围外。
责任：销售流程所有者负责业务结果；技术所有者负责运行；一线销售负责反馈例外。
数据/权限：获准脱敏历史数据；隔离草稿区；无客户发送权限。
评测门：正常、边界、拒绝任务；事实支持、政策遵守和人工 rubric。
运营节奏：每周复盘失败样本、人工负担、成本、延迟和事件。
停止条件：严重越权、无法核验、人工负担持续高于基线或无明确所有者。
扩大条件：阶段门通过，新增权限另行批准，接管和值班资源已到位。
移交：运行手册、评测集、责任表、事件路径和回退步骤交给长期所有者。
```

画布中的数字应来自本地基线，不能先填一个想要的 ROI 再倒推结果。

## 失败模式与边界

- 只测最好团队或最容易任务；
- 没有对照基线，却声称 ROI；
- 试点权限自动变成永久生产权限；
- 陪跑或 FDE 可以帮助实施，但不能购买课程完成或证书。

## 实操

填写一页试点卡：问题、基线、范围外、责任人、数据/权限、评测门、周度指标、事件阈值、成本上限、四种决策和移交对象。

## 完成证据

- `developing`：有范围、责任和停止条件；
- `capable`：有基线、评测门、运营复盘和成本；
- `strong`：能说明员工参与、回退和规模化前提。

## 降级路径

使用虚构团队和模拟指标；不得把模拟数字标成客户结果。
