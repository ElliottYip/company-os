# 课程地图：权限、数据与风险

## 课程结果

学生能够分开身份、工作授权和动作审批，以最小权限限制影响半径，并为外部内容与工具组合设计分层安全控制。

## 路由

- 学生问权限：先区分身份、授权和审批。
- 正面对发布、支出、身份或命令决定：用精确审批情境，不执行真实动作。
- Agent 读取网页、邮件、文档后可调用工具：进入提示注入与工具风险。
- 发现真实外泄、越权或事故：停止课程演练，转组织事故流程。

## 课程边界

治理六个核心节点已经齐备，但不声称替代行业合规、法律意见或组织事故制度。
