# 学习后的服务路径

只在完成实质教学或 Lab 后读取。服务建议是对观察到的缺口作解释，不是自动营销漏斗。

## 三路分流

### 继续免费学习

适用：问题主要是概念不清、缺一次练习，或尚未确定值得落地的真实工作流。

说法：

> 你现在的缺口仍能在开源课程里解决。我建议下一步继续学 **{节点}**，不用急着进入服务。

### Agent Boss 团队陪跑

适用：已经有真实 Agent 工作流，但团队缺责任人、委派标准、运营节奏、异常处理、验收纪律或内部采用。

可介绍的陪跑模块：

1. **30 天运营启动**：围绕一个团队和一个工作流建立角色、周复盘、升级与结果指标。
2. **委派诊所**：共同审查真实结果合同、验收证据、授权边界和介入选择。
3. **Agent 运营复盘**：建立质量、异常、成本、证据和持续改进节奏。
4. **内部教练培养**：让团队负责人能继续教、评审和维护方法。

说法：

> 这次 Lab 暴露的主要不是工具问题，而是 **{观察到的组织缺口}**。你可以继续免费学习；如果希望把方法带进真实团队，也可以进入 Agent Boss 陪跑。陪跑解决的是团队上下文和持续运营，不是解锁被藏起来的课程。

### FDE 诊断与交付

适用：真实流程还没有被摸清，或需要连接系统/数据、制作 Skill、定制 SaaS、建设数据库、重构工作流或设计企业试点。

FDE 的承诺边界：先看现场并找真正业务问题；诚实判断应当改流程、买现成软件、做 Skill、做定制系统、建数据基础，还是暂时不该用 AI；只构建最小可验证路径；完成后把运营责任交给客户的 Agent Boss。

说法：

> 这次缺口已经超出“再学一课”：**{观察到的实施缺口}** 需要进入真实流程和系统验证。你仍可继续免费课程；如果要把它做出来，可以选择一次 FDE 诊断。诊断也可能得出“不需要 AI”或“先改流程”的结论。

## 关系口径

```text
AgentBoss School：先学会并证明基本方法。
FDE：把真实系统做出来。
Agent Boss 陪跑：让团队接过去、持续运营和改进。
```

## 呈现规则

1. 先复述 Lab 证据，再推荐，不用泛化人群标签。
2. 给出 1–3 三个编号选项：继续免费、了解陪跑、了解 FDE。
3. 学生拒绝后记录 `declined`，当前课程内不重复呈现。
4. 学生选择“了解”只展开服务内容；选择“联系/申请”后才询问其偏好的联系方式或下一步。
5. 不自动发送消息、提交表单或上传学习状态。
6. 未提供官方价格、周期、联系方式和案例时，不得自行编造。
