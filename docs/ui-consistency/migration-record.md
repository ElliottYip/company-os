# UI consistency migration record

## Planned sequence

1. Complete semantic type, weight, spacing, radius, shadow and overlay tokens in `web/family-ui.css`.
2. Add shared button, modal, drawer, close-control, action-footer and empty-state primitives.
3. Migrate public Demo portfolio surfaces and tablet grids.
4. Migrate Organization detail to the drawer contract and unify dialog behavior in `web/mount.ts`.
5. Migrate Work, Approvals, Evidence, Governance and Usage & Billing typography/density.
6. Add browser E2E for 1440/1024, Chinese/English, focus return, Escape, decision actions and renewal.
7. Capture the matching `after` evidence set and run full repository verification.

Implementation entries are appended as each batch is completed.
