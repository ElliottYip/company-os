# Company OS / ANC UI consistency gap audit

Date: 2026-08-28  
Runtime: local `public-demo`, deterministic fixture data, no external calls  
Evidence: `output/playwright/ui-consistency-before/manifest.json` and its 40 screenshots

## Admission result before remediation

- Runtime integrity: passed. All 40 captures reported zero page-level horizontal overflow and zero console warnings/errors.
- Product boundary: passed. Demo remained explicitly labelled and no formal credential, model, Connector, enterprise data, or production capability was synthesized.
- Visual and secondary-interaction consistency: failed. The P1 findings below block acceptance.

## Page and component gaps

| ID | Severity | Surface | Observed gap | Required migration |
| --- | --- | --- | --- | --- |
| VIS-001 | P1 | Demo Dashboard, Agents, Work, Approvals, Governance, Usage & Billing | Public Demo portfolio surfaces use a parallel 18px-radius, shadow-heavy card language and local type sizes instead of the product shell contract. | Move portfolio surfaces onto shared radius, shadow, spacing, type and status tokens. |
| VIS-002 | P1 | Approvals, Usage & Billing | Approve, Reject, Trigger workflow and Request renewal render as browser-default buttons. Priority, danger and focus states are therefore inconsistent and weak. | Apply shared primary, secondary and danger button primitives. |
| VIS-003 | P1 | Agents at 1024px, both languages | Three narrow columns remain active. Runtime/privacy identifiers wrap into fragments such as `PRIVATE_A / CTIVITY_EX / CLUDED`. | Use the tablet two-column contract and safe identifier wrapping; do not abbreviate or alter source values. |
| VIS-004 | P1 | Shared shell and dialogs | `web/styles.css` still contains many local 8–25px declarations and references an undefined `--type-title`. Headings, helper text, labels and numbers do not share one complete scale. | Complete semantic type/weight/leading tokens and migrate customer-facing product surfaces. |
| VIS-005 | P2 | Demo Dashboard | Six independent metric cards give equal prominence to unequal data and consume the first viewport. | Use the compact shared metric strip and retain the existing information hierarchy and copy. |
| VIS-006 | P2 | Governance and Usage & Billing | Card height, padding and badge density differ from Work and Approvals; renewal timestamps wrap without a readable date policy. | Apply shared panel/list density and tabular metadata wrapping. |
| VIS-007 | P2 | Evidence | Empty state uses a different title/description scale and substantially different vertical density from other empty states. | Use the shared empty-state primitive and semantic type roles. |
| VIS-008 | P2 | Front door at 1024px | The front door is coherent, but its button, helper and footer type sizes are local literals rather than semantic roles. | Migrate without changing the approved content-first layout or brand voice. |
| INT-001 | P1 | Organization list → human/Agent detail | A record opens as a centered 560px modal even though it is contextual inspection/editing. The position obscures list context and does not match task-detail behavior. | Use a right-side detail drawer at desktop/tablet and a full-width sheet on narrow screens. |
| INT-002 | P1 | All native dialogs | Setup, editor, detail, restore and command dialogs duplicate overlay, radius, shadow, size and close-control rules. Focus return and initial-focus behavior are implemented ad hoc. | Introduce shared modal/drawer primitives and one dialog controller for open, close, focus restoration and backdrop behavior. |
| INT-003 | P1 | Approval and rejection | High-risk decisions use inconsistent visual priority; the public Demo exposes direct default buttons without a review-action footer contract. | Keep the exact existing action binding, but render the review state and actions through shared decision primitives. |
| INT-004 | P1 | Evidence viewing | Evidence records are visually list-like but expose no consistent contextual inspection contract. | Treat evidence inspection as a drawer/read-only detail contract; keep evidence admission semantics unchanged. |
| INT-005 | P2 | Company switcher popover | Escape closes the menu, but outside-click dismissal and focus return are not consistently enforced. | Add popover outside-click dismissal and deterministic focus return. |
| INT-006 | P2 | Dialog responsive behavior | Centered modal widths are individually defined and do not share tablet/mobile safe-area or internal scrolling rules. | Apply one responsive overlay sizing and scroll contract. |
| STATE-001 | P2 | Create/edit/decision actions | Action failure has a global banner, but pending state, disabled state and return focus are not consistently attached to the initiating surface. | Standardize busy/disabled semantics while preserving the existing authoritative server error boundary. |
