# 一家追着太阳工作的公司

## Problem Statement

如何用一个具有电影记忆点的未来场景，让企业决策者直观感受到：Company OS 能让分散在世界各地的人与 Agent 作为同一家公司持续协作，同时把人的生活、判断和责任保留在中心？

## Recommended Direction

拍摄一家完全分布式的互联网公司在一个完整日照循环中发布一项线上产品功能。任务随着日光经过峡湾渡轮、雪线列车、山谷住宅、高山湖和临海小镇。每位员工只在自己真正需要作出判断的时刻进入工作；Agent 团队负责整理用户反馈、协调任务、生成发布内容、追踪证据和保持上下文。

Company OS 是全片唯一持续存在的“公司空间”。FDE 在真实业务现场发现问题并改变任务路径，Generator 将已确认的信息转化为可发布内容。风景不是装饰，而是证明这家公司已经不依赖同一个地点、同一时区或所有人同时在线。

核心观点：**未来的工作，不是让工作无处不在，而是让人不必一直在场。**

## Key Assumptions to Validate

- [ ] Company OS 当前界面足以清楚展示组织、Agent 状态、任务、审批、证据和责任链；拍摄前用真实 Demo 逐项确认。
- [ ] Generator 当前可以公开展示从已确认资料到可发布内容的完整链路；若不能，则缩小到真实可演示的单一产物。
- [ ] 制作预算或生成能力可以保证五个以上自然场景的人物、服装、设备和光线连续性；先做 20 秒概念预告验证。
- [ ] 观众能够理解“度假中短暂审批”代表获得自由，而不是工作侵入生活；用镜头时长和文案明确人只处理关键判断。
- [ ] 全片使用一个可公开的真实项目或明确标注的合成任务，不把虚构结果包装成客户案例。

## MVP Scope

先制作一支 20—30 秒概念预告：渡轮日出、用户访谈、雪线列车、Company OS 审批、Agent 继续执行、日落发布。验证日光接力、人物自由和产品存在感是否能同时成立，再扩展为主片。

## Not Doing (and Why)

- 不拍连续 Zoom 会议——会退化成传统远程办公广告。
- 不让每个场景都有人盯着电脑——与“Agent 让人不必一直在场”的核心冲突。
- 不使用无关风景蒙太奇——每个地点都必须完成任务链中的一个动作。
- 不宣称 Agent 取代人——目标、例外、审批和最终责任必须清楚属于人。
- 不同时平均介绍所有产品——Company OS 是叙事主轴，FDE 和 Generator 只在任务需要时出现。
- 不使用未经证实的效率数字、客户结果或产品能力——以真实界面和可验证行为建立可信度。

## Open Questions

- 主片首先服务中文企业客户，还是同时规划无对白的国际版本？
- 最终贯穿全片的互联网任务采用新功能发布、线上社区开放，还是另一项真实项目？
- 风景采用全实拍、全 AI 生成，还是人物实拍加 AI 环境？
